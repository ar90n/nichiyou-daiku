# 定尺の設定（Stock Lengths）設計

- 日付: 2026-10-15
- ステータス: 設計済み
- 対象: M4-2（製作支援: 店の売り長さで木取りと購入を計算する）
- 進め方: 既存の report の流れへの追加なので、計画書は書かずにこの記録から TDD で実装する

## 背景

木取りと購入の推奨は定尺を固定値で計算している（1x 材 1830/2440/3050mm、2x 材 2440/3050/3660mm）。Python API の
`generate_markdown_report` は定尺を受け取れるが CLI からは渡せず、鋸の刃厚（3mm）はどこからも変えられない。既定値は
北米の売り方に近く、日本のホームセンターで最もよく見る 2x4 の 6F（1820mm）が入っていない。

## 目的

report の購入の推奨と木取りが、使う店で実際に売っている長さで出る。一度書いておけば、どの設計にも使える。

## 合意した方針（決定事項と理由）

1. **定尺と刃厚は小さなファイル（TOML）に書き、`report --stock FILE` で渡す**（ユーザーの選択）。店ごとに 1 つ作れば
   どの設計にも使い回せる。CLI のオプションに並べる案は材種が多いと長くなり、.nd に書く案は設計と買い物が混ざる。
2. **既定の定尺は日本のホームセンターに合わせる**（ユーザーの選択）。すべての材種で 6F・8F・10F・12F
   （1820・2440・3050・3650mm）。刃厚の既定は 3mm のまま。
3. **書いていない材種は既定値を使う。** よく使う材種だけ書けばよい。

## 設計

- ファイルの形:

  ```toml
  kerf = 2                         # 鋸の刃厚 mm（省略時 3）

  [lengths]                        # 材種ごとの定尺 mm。書いていない材種は既定値
  "2x4" = [1820, 2440, 3050, 3650]
  "1x4" = [910, 1820]
  ```

- **新規 `shell/stock.py`**: `Stock(lengths, kerf)` と `load_stock(path) -> Stock`。標準ライブラリの `tomllib` だけを使う。
  次は「何が悪く、どう直すか」を書いた例外（`StockFileError`）で止める: 読めない・TOML の誤り、知らないキー
  （`lenghts` など）、知らない材種（使える材種を並べる）、空のリスト・0 以下の長さ、負の刃厚。
- `shell/cutting.py`: `DEFAULT_STANDARD_LENGTHS` を上の既定値に。
- `generate_markdown_report` に `kerf` を足し、`plan_cuts` に渡す。購入の推奨の節の頭に使った刃厚を書く（`Saw kerf: 2mm per cut`。木取りの節は `--no-cut-diagram` で消えるが、刃厚は購入の推奨にも効くため。実装時に変更）。
- CLI `report --stock FILE`: 誤りはメッセージを出して終了コード 1。
- スキル: 利用者が店の売り長さを言ったら `stock.toml` に書いて `--stock` で渡す。
- ドキュメント: DSL 仕様の report の節（`--stock` とファイルの形）、API 仕様（`load_stock`、`kerf`、新しい既定値）。

## テスト

- `load_stock`: 既定値との合成、刃厚の省略、誤りごとのメッセージ。
- report: 購入の推奨と木取りが渡した定尺と刃厚を使う、刃厚の行。
- CLI: `--stock` で効く、壊れたファイルで終了コード 1 とメッセージ。
- 既定値が変わったことで古い長さを前提にしたテストを新しい値に直す。
