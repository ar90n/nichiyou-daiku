# 正面図の向き 設計

- 日付: 2026-10-17
- ステータス: 実装済み
- 対象: M4 の後片付け（M4-4 の作業中に見つけた別件）

## 背景

図面（`drawing`）と確認画像（`render`）の正面図は -y から、右側面図は +x から見ていた。設計スキルの決まりでは家具の正面は
+y（脚の front 面を家具の正面に向ける。例の `apron_front` は +y 側、`apron_back` は 0 側）、左は +x（`apron_left` は
+x 側）なので、正面図には家具の後ろが、右側面図には左側面が描かれていた。3 面図そのものは、-y 側に立つ人から見た第三角法
として筋が通っていた。

## 決定と理由

1. **家具の正面は +y、左は +x とし、見る向きをそれに合わせる**（ユーザー承認）。設計スキルの決まりと例の部材名がそうなって
   いるため。ワールドの座標と `validate --json` は変えない（変えると既存の .nd とスキルの説明がすべて食い違う）。
2. **正面図は +y から、右側面図は -x から、平面図は +z から正面を下にして見る**。第三角法の配置（平面図が上、右側面図が右）は
   そのまま。平面図の左右と正面図の左右、右側面図の上下と正面図の上下がそろい、正面の辺が正面図の側に来る。
3. **立体図は -x +y +z から**（ユーザー選択。案は今の +x +y +z）。正面・右・上が見え、3 面図と同じ側になる。図面・render・
   手順の画像の立体図はこの 1 つを使う。
4. **部品図と手順の寸法図は変えない**。部品図は部材の軸で描き、手順の寸法図は手順ごとに見る向きを選ぶため。

## テスト

- 正面図に apron_upper_front が見え apron_upper_back が隠れる、右側面図に apron_upper_right が見え apron_upper_left が隠れる
  （2 段の棚）。
- 平面図と正面図の横、右側面図と正面図の縦がそろい、正面の辺が平面図の下・右側面図の左に来る。
