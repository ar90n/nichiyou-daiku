# R3c3 マニュアルと印刷（ビューアー） 設計

- 日付: 2026-11-01
- ステータス: 設計（未実装）
- ブランチ: `next`（作業は `next-r3c3-manual`）
- 親: `2026-10-29-next-generation-rust-core-design.md`（R3 組み立てマニュアルの C3）、
  `2026-11-01-r3c1-part-drawings-design.md`（部品図）、`2026-11-01-r3c2-step-drawings-design.md`（手順の図）

## 目的

部品表・部品図・手順の図を 1 つのページに並べ、ビューアーで通して読み、A4 で印刷できるようにする。R3 組み立て
マニュアルの最後で、作業場に紙で持っていけるようにする。

## 決定と理由

1. **ビューアーの中に Manual タブを置く**（ユーザー）。左の欄と 3D の場所を使ってマニュアルを縦に並べ、
   [Print] でブラウザの印刷を開く。手元のファイル（URL の無いもの）でもスマホでもそのまま使える。別のタブ
   （ページ）で開く案は、手元のファイルの中身を渡す仕組みが要り、スマホでタブを行き来することになるので
   選ばなかった。印刷だけで画面に出さない案は、画面で通して読めないので選ばなかった。
2. **A4 横に印刷する**（ユーザー）。図は幅 280mm で組んであり（数字の高さ 2.5mm）、A4 横の使える幅 277mm に
   ほぼそのまま入る。手順は 1 ページに 1 つ。A4 縦は図を 0.68 倍に縮め（数字 1.7mm）、込み入った寸法図が
   読みにくくなるので選ばなかった。
3. **中身は CLI の `steps.md` と同じ順**: 部品表 → 部品図 → 手順ごとに図・部材の表・金物の表。1 ページ目には
   買い物と切り出しに使う「用意するもの」として、部品表と金物の合計を置く（`steps.md` には無い）。設計に問題
   （重なりなど）があれば、その一覧も 1 ページ目に置く。紙だけを見る人にも分かるようにするため。
4. **TypeScript で組む。Rust と WASM は変えない**（ユーザー承認）。図はすでに Rust が描いており（C1 の
   `part_drawing`、C2 の `step_drawing`）、残りは並べ方と印刷なので HTML と CSS で足りる。Rust で HTML を組む
   案は、表や見出しの HTML を Rust に持ち web の CSS と離れるので選ばなかった。Rust で A4 のページを SVG で
   組む案は、表を自前で描く分が多く、決まった大きさのページはスマホで小さくなるので選ばなかった。後の CLI
   （R4）が同じマニュアルを書き出したくなったら、そのときに移す。
5. **ページ番号では参照しない**。HTML の印刷ではページ番号が決まらないので、部品表の番号と部品図の「Part N」
   で対応させる。
6. **入りきらない数値の知らせは、その図のすぐ下に文字で出す**（画面でも紙でも）。紙のどこに数値が欠けて
   いるかが分かるように。
7. **図は図の欄と同じキャッシュを使う**。部品図・手順の図はファイルごとに一度だけ作り、ファイルを開き直したら
   捨てる。

## ページ

A4 横、余白 10mm（使える幅 277mm、高さ 190mm）。

1. **用意するもの**（1 ページ目）
   - 題名 `<名前>: assembly manual`（CLI の `steps.md` の `<名前>: assembly steps` にならう）と全体の大きさ
     （W × D × H）。
   - 部品表: 番号・Pieces・Lumber・Length (mm)・Count。番号は穴のある部品だけに付け（`Part 1`…、部品表の
     順）、部品図の見出しと同じにする。
   - 金物の合計: Fastener・Count（手順ごとの金物を名前ごとに足し、最初に出た順）。金物が無ければ出さない。
   - 問題: 設計に問題があるときだけ、その文の一覧。
2. **部品図**: 新しいページから。穴のある部品ごとに見出し「Part N」と C1 の図。図の途中ではページを切らず、
   入るだけ 1 ページに並べる。図がページの高さを超えるときは高さに合わせて縮める。
3. **手順**: 手順ごとに新しいページ。C2 の図（見出しは図の中）の下に、今回の部材の表（Piece・Lumber・
   Length (mm)）と金物の表（Fastener・Count）を横に並べる。入らないときは表だけ次のページに続く。

図を作れないときは、その図の場所に理由の文を出す。

## 組み立て（web だけ）

- `manual.ts`（新規）
  - `fastenerTotals(steps)`: 金物の合計（名前ごと、最初に出た順）。純粋な関数。
  - `renderManual(root, view, name, draw)`: マニュアルの DOM を組む。`draw` は部品図（部品表の番号）と
    手順の図（1 から）の `DrawingAnswer` を返す関数の組で、テストでは偽物を渡す。表は `panels.ts` の
    `element` で、今の部品表と同じ見た目にする。
- `index.html`: タブに `Manual`。`main` の中に `#manual`（上に [Print] の帯、下にページ）。
- `main.ts`
  - タブの状態を model・steps・manual の 3 つにする。Manual を押せる条件と押せないときの理由は Steps と同じ
    （`stepsTab`）。
  - Manual を開くと「Making the drawings…」を出し、core を待ってすべての図を作って並べる（決定 7 の
    キャッシュ）。core が読めなければ、マニュアルの場所に再読み込みを促す文を出す。
  - Manual を開いたままファイルを開き直したら、新しいファイルで組み直す。Manual では URL の `?step=` を消す
    （Model と同じ）。
- `style.css`
  - `body.manual-mode`: 左の欄と 3D を隠し、`#manual` を `main` いっぱいに出す。画面ではページを白い紙
    （最大幅 297mm、影）として縦に並べる。
  - `@media print`（manual-mode のときだけ効く）: `@page { size: A4 landscape; margin: 10mm }`、ヘッダー・
    タブ・[Print] の帯を隠す、部品図の始まりと手順のページに `break-before: page`、図に
    `break-inside: avoid`、SVG は幅 100%・高さはページに収まるまで。Model や Steps で印刷したときは今のまま。
- README: Manual と印刷の段落。

## テスト

- `fastenerTotals`: 手順をまたいで同じ名前を足す、最初に出た順、金物の無い設計で空。
- `renderManual`（偽の `draw`）: 1 ページ目の題名・全体の大きさ・番号つきの部品表・金物の合計、問題があると
  きだけの問題の一覧。部品図は穴のある部品だけで番号が部品表と合う。手順ごとに 1 ページで、図の下に部材と
  金物の表。知らせが図の下に出る。図を作れないときは理由の文。
- タブ: Manual が Steps と同じ条件で押せ、押せないときは理由が出る。
- 印刷の CSS: スタイルシートを読み込んだ jsdom で、manual-mode のときに部品図の始まりと手順のページに改ページの
  指定が付くこと。`@page` の A4 横がスタイルシートにあること。
- 見た目: ファイルワゴンのマニュアルを Tailscale 経由で開き、ユーザーが PC で印刷プレビュー（または PDF）を、
  スマホで画面の表示を確かめる。

## C3 で作らないもの

木取り（定尺からの切り方。Rust の core にまだ無く、R4 の report で移す）、マニュアルを指す URL、ページ番号での
相互参照、CLI でのマニュアルの書き出し（R4）。

## C3 が終わる条件

- 上のテストがすべて通り、`make check` と `make ci-local` が通る。
- ユーザーが PC で印刷を、スマホで画面の表示を確かめた。
- これで R3 組み立てマニュアルが終わる。次は R4 CLI。
