# ビスを部材の狭い面から通せるようにする（座掘り） 設計

- 日付: 2026-10-22（座掘りは 2026-10-23）
- ステータス: 実装した（ブランチ feat/screw-narrow-face）
- 対象: M5-3（実際の家具で使い倒す）で見つかった制約

## 背景

デスク下のファイルワゴン（2x4 と 1x4、留め具はビスだけ）で、天板の上の 3 面の柵を幕板と同じく柱と柱の間に
通そうとした（ユーザーの要望）。後ろの角の柱には、背面の柵と横の柵が直角の 2 方向から突き当たる。ビスの
target（ビスが貫く部材）は front/back（広い面）で接する決まりだったので、柱の広い面は向かい合う 2 面しかなく、
片方の柵しか留められなかった。

最初は狭い面を長いビスで真っ直ぐ貫く形（2x4 の 89mm を 5.2×120 で貫き、相手に 31mm）にした。ユーザーから
「89mm にビスを打つのは一般的か」と聞かれ、一般的ではない（まっすぐ打ち抜くのが難しく、木口に浅くしか効かない）
と答えた。このプロジェクトの要は「簡単な工作でできる範囲で設計する」こと（ユーザー）なので、DIY でふつうに
使う座掘り（太いドリルで決まった深さまで穴を掘り、ビスの頭を沈める）に変えた。斜め打ちより工作が簡単で、
ライブラリでも面に垂直な穴のまま表せる。

## 決定と理由

1. **target は木口（top/down）以外の 4 つの側面で接してよい。** top/down は、ビスが部材の長さの向きに走って
   しまうので、引き続き断る。
2. **狭い面から通すときは、ライブラリが自動で座掘りする**（ユーザーが自動を選んだ）。深さは「広い面から
   通すときと同じ厚さだけ材が残る」まで（2x4 なら 89 − 38 = 51mm）。ビスはどちらの面からでも target の
   厚さを貫くので、長さの決まりと推奨のビス（2x4 どうしなら 3.8×65）が同じになり、DSL の書き方も増えない。
   座掘りの深さを `.nd` に毎回書く形にもできたが、書き方が増え、深さの決め方も人によって変わるので選ばない。
3. **座掘りの径は、ビス径 4.5mm 以下は 10mm、それより太いと 12mm。** ビスの頭が沈む太さで、座掘り用の
   ビットによくある径。
4. **座掘りは下穴と同じ「穴」として扱う。** target の反対の面から、下穴と同じ軸に掘る、太くて浅い穴として
   `Fastener.counterbore` に持ち、`Assembly.pilot_holes` にも入れる。レポートのドリルと下穴の表、3D、
   図面は何も変えずに座掘りを出せる。
5. **ぶつかりの判定は座掘りの太さで行う。** 1 つの部材の中で別の接続の穴どうしが当たると validate がエラーに
   する（ユーザーの要望で、角の柱で確かめるテストを足した）。座掘りはビスより太いので、座掘りの太さで判定する。
   同じ接続の穴どうしは比べない（ビスは自分の座掘りの中を通る）。
6. **同じ高さで直角に来る 2 本を、どちらも柱を貫くビスで留めると、ビスは柱の中で必ず交わる。** これは
   validate が見つけるので、設計の側で片方の高さをずらす（仕様の「長さの選び方」に書いた）。ビスの位置を
   自動でずらす仕組みは入れない（接続ごとの配置が、ほかの接続に左右されないままにしておく）。
