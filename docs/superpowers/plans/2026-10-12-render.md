# render (Check Image) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `nichiyou-daiku render design.nd` writes one square PNG with four accurate build123d views of the model, labelled with piece IDs, and the design skill looks at it.

**Architecture:** A build123d-free `shell/views.py` holds the four view directions (shared with the technical drawing) and decides where piece labels go (projection math plus a ray–box occlusion test on the placement boxes). `shell/render.py` projects the build123d part (visible lines only), lays the views out 2×2 on a square sheet, adds captions, labels and a note as SVG text, and converts to PNG with cairosvg. A `render` CLI command, the plugin wrapper, the DSL spec and the skill use it.

**Tech Stack:** Python 3.13, build123d (`project_to_viewport`, `ExportSVG`, `scale`, `Pos`), cairosvg, numpy, click, pytest.

**Spec:** `docs/superpowers/specs/2026-10-12-render-design.md`

## Global Constraints

- Branch `feat/render`. `make check` before every commit. Code, comments, CLI help and skill text in English; specs stay Japanese.
- Shapes come from `convert_assembly_to_build123d` (same as drawing/export; holes and `--fillet-radius`, default 5). Visible lines only.
- The four views are the drawing's: from +z (column 0, row 0), from -y (0, 1), from +x +y +z (1, 0), from +x (1, 1). The technical drawing's output must not change.
- Captions name only the viewing direction: `from +z`, `from -y`, `from +x`, `from +x +y +z` (spec amendment, Task 1: "front"/"top" would clash with the DSL's face names — `top` is a piece's end — and the -y view shows the back of a model whose legs face +y).
- Viewport projection (verified against build123d while planning): with N = unit(origin) and Y = unit(up − (up·N)N), a world point p lands at (p·(Y×N), p·Y).
- A label is skipped in a view when another piece's box lies between its center and the viewer, or when it would overlap a label already placed in that view (spec amendment, Task 1). Pieces labelled in no view are listed in the note as `not labelled: ...`.
- Sheet: square, default 1400px (`--size`, at least 400); margins and caption band 4% of the size; the largest view fills 90% of a cell's drawing area; lines `max(1, size/1000)` px wide (thinner lines all but vanish: 0.2px at size 200 left 3 dark pixels in a trial); labels `max(10, size/80)` dark red with a white outline; captions `max(12, size/50)`; note `max(10, size/60)` at the bottom left: `<file name>  <x> x <y> x <z> mm (x × y × z)` or `<file name>  pieces not connected`, then, when some pieces have no label, `not labelled: a, b, ...` on its own lines wrapped to the sheet width, stacked upward from the bottom (on one line the shelf's note is ~1410px, wider than the 1288px available at 1400).
- `render_sheet` stops with a clear error unless build123d's SVG is one group flipped by `scale(1,-1)` (hard-coded in build123d's exporter today); the text placement relies on it.
- Plan revised after an outside review (DeepSeek, 2026-10-13), each point checked here: line and font floors, the note wrapping, the SVG guard and a self-contained Task 5.
- `render` needs build123d (viz extra); `bin/nichiyou-daiku` treats `render` like `export`/`drawing`/`view`. Stdin needs `-o`; never overwrite the input (same helpers as `drawing`).
- `shell/render.py` is not imported by `nichiyou_daiku.shell.__init__`.

"""The four directions a model is drawn from, and where piece labels go.

Shared by the technical drawing and the check image. Free of build123d: the
projection is the one build123d's ``project_to_viewport`` uses when looking at
the origin, so a label placed here lands on the projected lines.
"""

from typing import NamedTuple, Sequence

import numpy as np

from nichiyou_daiku.core.assembly import Assembly

# A ray that only grazes a face or an edge of a box is not hidden by it
_TOLERANCE_MM = 1e-6


class View(NamedTuple):
    """A viewing direction and its place on a 2x2 sheet (column and row
    counted from the top left)."""

    caption: str
    origin: tuple[float, float, float]
    up: tuple[float, float, float]
    column: int
    row: int


# The order is the order the technical drawing writes its edges in
VIEWS = (
    View("from +z", (0, 0, 100), (0, 1, 0), 0, 0),
    View("from -y", (0, -100, 0), (0, 0, 1), 0, 1),
    View("from +x +y +z", (100, 100, 100), (0, 0, 1), 1, 0),
    View("from +x", (100, 0, 0), (0, 0, 1), 1, 1),
)


class Label(NamedTuple):
    """A piece ID at a point of the viewport."""

    piece_id: str
    x: float
    y: float


def _unit(vector: Sequence[float] | np.ndarray) -> np.ndarray:
    v = np.asarray(vector, dtype=float)
    return v / np.linalg.norm(v)


def project(view: View, point: Sequence[float]) -> tuple[float, float]:
    """Viewport coordinates of a world point, as build123d projects it."""
    toward_viewer = _unit(view.origin)
    up = np.asarray(view.up, dtype=float)
    up = _unit(up - up.dot(toward_viewer) * toward_viewer)
    p = np.asarray(point, dtype=float)
    return float(p @ np.cross(up, toward_viewer)), float(p @ up)


def _blocks(
    start: np.ndarray, direction: np.ndarray, low: np.ndarray, high: np.ndarray
) -> bool:
    """Whether the ray from ``start`` along ``direction`` passes through the
    inside of the box ``low``..``high``."""
    near, far = 0.0, np.inf
    for axis in range(3):
        if abs(direction[axis]) < 1e-12:
            inside = low[axis] + _TOLERANCE_MM < start[axis] < high[axis] - _TOLERANCE_MM
            if not inside:
                return False
            continue
        t1 = (low[axis] - start[axis]) / direction[axis]
        t2 = (high[axis] - start[axis]) / direction[axis]
        near, far = max(near, min(t1, t2)), min(far, max(t1, t2))
    return far - near > _TOLERANCE_MM


def visible_labels(assembly: Assembly, view: View) -> list[Label]:
    """Labels at the centers the viewer can see: no other piece lies between
    a piece's center and the viewer. In model order."""
    boxes = {}
    for piece_id, piece in assembly.model.pieces.items():
        low, high = assembly.placement.poses[piece_id].bounds(piece)
        boxes[piece_id] = (
            np.array([low.x, low.y, low.z]),
            np.array([high.x, high.y, high.z]),
        )
    toward_viewer = _unit(view.origin)
    labels = []
    for piece_id, (low, high) in boxes.items():
        center = (low + high) / 2
        hidden = any(
            _blocks(center, toward_viewer, *box)
            for other, box in boxes.items()
            if other != piece_id
        )
        if not hidden:
            labels.append(Label(piece_id, *project(view, center)))
    return labels
```

"""The check image: four views of a model on one square sheet, with piece
labels, for an agent or a person to look at.

Needs build123d, so ``nichiyou_daiku.shell`` does not import this module.
"""

import tempfile
import textwrap
import xml.etree.ElementTree as ET
from dataclasses import dataclass
from pathlib import Path
from typing import NamedTuple

import cairosvg
from build123d import Compound, ExportSVG, Pos, Unit, scale

from nichiyou_daiku.core.assembly import Assembly
from nichiyou_daiku.core.placement import overall_bounds
from nichiyou_daiku.shell.diagnostics import format_mm
from nichiyou_daiku.shell.views import VIEWS, visible_labels

SVG_NAMESPACE = "http://www.w3.org/2000/svg"
ET.register_namespace("", SVG_NAMESPACE)

VIEW_FILL = 0.9
"""Share of a cell's drawing area taken by the largest view."""

_MARGIN = 0.04
"""Margin and caption band, as a share of the sheet size."""


@dataclass(frozen=True)
class PlacedLabel:
    """A piece ID on the sheet, in px with y up from the bottom."""

    caption: str
    piece_id: str
    x: float
    y: float


@dataclass(frozen=True)
class Sheet:
    """The SVG of the check image and what was placed on it."""

    svg: str
    size: int
    labels: tuple[PlacedLabel, ...]
    view_boxes: dict[str, tuple[float, float, float, float]]
    unlabelled: tuple[str, ...]
    note: tuple[str, ...]

    def png(self) -> bytes:
        return cairosvg.svg2png(
            bytestring=self.svg.encode(),
            output_width=self.size,
            output_height=self.size,
            background_color="white",
        )


class _Text(NamedTuple):
    x: float
    y: float
    text: str
    size: float
    color: str
    anchor: str


def _overlaps(
    a: tuple[float, float, float, float], b: tuple[float, float, float, float]
) -> bool:
    return a[0] < b[2] and b[0] < a[2] and a[1] < b[3] and b[1] < a[3]


def _note(
    assembly: Assembly, title: str, unlabelled: list[str], width: int
) -> list[str]:
    """The note's lines: the title and size, then the unlabelled pieces
    wrapped to ``width`` characters."""
    if len(assembly.placement.groups) == 1:
        low, high = overall_bounds(assembly.model, assembly.placement)
        sizes = " x ".join(
            format_mm(value) for value in (high.x - low.x, high.y - low.y, high.z - low.z)
        )
        head = f"{title}  {sizes} mm (x × y × z)"
    else:
        head = f"{title}  pieces not connected"
    if not unlabelled:
        return [head]
    return [head, *textwrap.wrap("not labelled: " + ", ".join(unlabelled), width)]


def _svg(exporter: ExportSVG, texts: list[_Text], size: int) -> str:
    with tempfile.TemporaryDirectory() as tmp:
        path = Path(tmp) / "sheet.svg"
        exporter.write(str(path))
        root = ET.fromstring(path.read_text())
    groups = list(root)
    if len(groups) != 1 or groups[0].get("transform") != "scale(1,-1)":
        raise RuntimeError(
            "Unexpected SVG from build123d: expected one group flipped with "
            "scale(1,-1), so the labels would not line up with the lines"
        )
    # The exporter fits its view box to the lines; the sheet is the whole
    # square. Lines are drawn in a y-up group, so y is negated here and below.
    root.set("width", str(size))
    root.set("height", str(size))
    root.set("viewBox", f"0 {-size} {size} {size}")
    for text in texts:
        # A white outline underneath keeps the text readable across lines
        outline = {"stroke": "white", "stroke-width": f"{text.size / 5:.2f}"}
        for extra in (outline | {"fill": "white"}, {}):
            element = ET.SubElement(
                root,
                f"{{{SVG_NAMESPACE}}}text",
                {
                    "x": f"{text.x:.2f}",
                    "y": f"{-text.y:.2f}",
                    "font-family": "sans-serif",
                    "font-size": f"{text.size:.2f}",
                    "text-anchor": text.anchor,
                    "dominant-baseline": "middle",
                    "fill": text.color,
                    **extra,
                },
            )
            element.text = text.text
    return ET.tostring(root, encoding="unicode")


def render_sheet(
    part: Compound, assembly: Assembly, *, title: str, size: int = 1400
) -> Sheet:
    """Draw the visible lines of ``part`` from the four ``VIEWS`` on a square
    sheet ``size`` px wide, at one scale, with captions, piece labels and a
    note naming ``title`` and the overall size."""
    margin = size * _MARGIN
    caption_height = size * _MARGIN
    cell = (size - 2 * margin) / 2
    # Floors keep small images readable
    label_size = max(10.0, size / 80)
    caption_size = max(12.0, size / 50)
    note_size = max(10.0, size / 60)

    projected = []
    for view in VIEWS:
        visible, _ = part.project_to_viewport(view.origin, view.up, look_at=(0, 0, 0))
        lines = Compound(children=list(visible))
        projected.append((view, lines, lines.bounding_box()))
    largest = max(max(box.size.X, box.size.Y) for _, _, box in projected)
    view_scale = (cell - caption_height) * VIEW_FILL / largest if largest > 0 else 1.0

    exporter = ExportSVG(unit=Unit.MM)
    exporter.add_layer("Visible", line_weight=max(1.0, size / 1000))
    texts: list[_Text] = []
    labels: list[PlacedLabel] = []
    view_boxes: dict[str, tuple[float, float, float, float]] = {}
    for view, lines, box in projected:
        center_x = margin + view.column * cell + cell / 2
        cell_top = size - margin - view.row * cell
        center_y = cell_top - caption_height - (cell - caption_height) / 2
        dx = center_x - box.center().X * view_scale
        dy = center_y - box.center().Y * view_scale
        exporter.add_shape(Pos(dx, dy) * scale(lines, view_scale), layer="Visible")
        view_boxes[view.caption] = (
            dx + box.min.X * view_scale,
            dy + box.min.Y * view_scale,
            dx + box.max.X * view_scale,
            dy + box.max.Y * view_scale,
        )
        texts.append(
            _Text(center_x, cell_top - caption_height / 2, view.caption, caption_size, "black", "middle")
        )
        taken: list[tuple[float, float, float, float]] = []
        for label in visible_labels(assembly, view):
            x = dx + label.x * view_scale
            y = dy + label.y * view_scale
            half = len(label.piece_id) * label_size * 0.3
            area = (x - half, y - label_size / 2, x + half, y + label_size / 2)
            if any(_overlaps(area, other) for other in taken):
                continue
            taken.append(area)
            labels.append(PlacedLabel(view.caption, label.piece_id, x, y))
            texts.append(_Text(x, y, label.piece_id, label_size, "#b00000", "middle"))

    labelled = {label.piece_id for label in labels}
    unlabelled = [piece_id for piece_id in assembly.model.pieces if piece_id not in labelled]
    # About 0.55 em per character in a sans-serif font
    note = _note(assembly, title, unlabelled, int((size - 2 * margin) / (note_size * 0.55)))
    for index, line in enumerate(reversed(note)):
        # The last line sits in the bottom margin; earlier lines stack above
        y = margin / 2 + index * note_size * 1.3
        texts.append(_Text(margin, y, line, note_size, "black", "start"))
    return Sheet(
        svg=_svg(exporter, texts, size),
        size=size,
        labels=tuple(labels),
        view_boxes=view_boxes,
        unlabelled=tuple(unlabelled),
        note=tuple(note),
    )
```

```python
"""Render command: a labelled four-view check image (PNG)."""

import sys
from pathlib import Path
from typing import Optional

import click

from nichiyou_daiku.cli.utils import (
    VIZ_INSTALL,
    CliEcho,
    convert_assembly_to_build123d,
    create_assembly_from_model,
    ensure_build123d_available,
    ensure_not_overwriting_input,
    parse_dsl_to_model,
    read_dsl_file,
    require_output_for_stdin,
)


@click.command()
@click.argument("input_file", type=str)
@click.option(
    "-o",
    "--output",
    type=click.Path(path_type=Path),
    help="Output PNG path (default: <input>.png, required for stdin).",
)
@click.option(
    "--size",
    type=click.IntRange(min=400),
    default=1400,
    show_default=True,
    help="Width and height of the image in pixels.",
)
@click.option(
    "--fillet-radius",
    type=float,
    default=5.0,
    help="Fillet radius in mm (default: 5.0, use 0 to disable)",
)
@click.pass_context
def render(
    ctx: click.Context,
    input_file: str,
    output: Optional[Path],
    size: int,
    fillet_radius: float,
) -> None:
    """Render a check image (PNG): four labelled views of the model.

    INPUT_FILE: Path to .nd file or '-' for stdin

    The views look from +z, -y, +x and +x +y +z, in the axes of the first
    piece declared (see validate --json). Each piece's ID is written where
    the viewer can see its center; pieces hidden in every view are listed
    in the note.

    \b
    Examples:
        nichiyou-daiku render table.nd
        nichiyou-daiku render table.nd -o check.png --size 1000
    """
    echo = CliEcho(ctx)

    ensure_build123d_available(echo)
    try:
        from nichiyou_daiku.shell.render import render_sheet
    except ImportError as e:
        echo.error(
            f"Error importing dependencies: {e}\n"
            f"Install the CLI with the viz extra: {VIZ_INSTALL}"
        )
        sys.exit(1)

    require_output_for_stdin(input_file, output)
    output_path = output or Path(input_file).with_suffix(".png")
    ensure_not_overwriting_input(input_file, output_path)
    title = output_path.name if input_file == "-" else Path(input_file).name

    model = parse_dsl_to_model(read_dsl_file(input_file), echo)
    assembly = create_assembly_from_model(model, echo)
    part = convert_assembly_to_build123d(assembly, echo, fillet_radius=fillet_radius)

    try:
        sheet = render_sheet(part, assembly, title=title, size=size)
        output_path.write_bytes(sheet.png())
    except Exception as e:
        echo.exception(f"Error rendering the image: {e}")
        sys.exit(1)

    echo.info(f"Successfully rendered: {output_path}")
```

"""Score the runs: skill used, validate passes, size matches, image looked at."""

import json
import subprocess
import sys
from pathlib import Path

CLI = "/home/argon/workspace/nichiyou-daiku/.venv/bin/nichiyou-daiku"
WANTED = {
    "side-table": [400, 500, 600],
    "two-tier-shelf": [300, 600, 800],
    "plant-stand": [300, 400, 700],
}

for run in sorted(p for p in Path(sys.argv[1]).iterdir() if p.is_dir()):
    case = run.name.rsplit("-", 1)[0]
    events = [json.loads(line) for line in (run / "run.jsonl").read_text().splitlines() if line.strip()]
    uses = [
        block
        for event in events
        if event.get("type") == "assistant"
        for block in event["message"]["content"]
        if block.get("type") == "tool_use"
    ]
    commands = [u["input"].get("command", "") for u in uses if u["name"] == "Bash"]
    skill = any(u["name"] == "Skill" and "design" in json.dumps(u["input"]) for u in uses)
    validates = sum("nichiyou-daiku validate" in c for c in commands)
    renders = sum("nichiyou-daiku render" in c for c in commands)
    reads_png = sum(
        u["name"] == "Read" and u["input"].get("file_path", "").endswith(".png")
        for u in uses
    )
    result = next((e for e in events if e.get("type") == "result"), {})
    minutes = round(result.get("duration_ms", 0) / 60000, 1)
    nd_files = sorted(run.glob("*.nd"))
    named = [p for p in nd_files if p.stem.replace("_", "-") == case]
    head = f"{run.name}: skill={skill} validate={validates} render={renders} read_png={reads_png} min={minutes}"
    if not nd_files:
        print(f"{head} NO .nd")
        continue
    nd = named[0] if named else nd_files[0]
    data = json.loads(subprocess.run([CLI, "validate", "--json", str(nd)], capture_output=True, text=True).stdout)
    size = sorted(data["overall_size"]) if data["overall_size"] else None
    match = size is not None and all(abs(a - b) <= 1 for a, b in zip(size, WANTED[case]))
    print(f"{head} valid={data['valid']} size={size} match={match} file={nd.name}")
